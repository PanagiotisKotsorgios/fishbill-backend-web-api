E-TIMOLOGIERA — ΗΛΕΚΤΡΟΝΙΚΗ ΤΙΜΟΛΟΓΗΣΗ ΑΑΑΔΕ

Πώς να δημιουργήσετε λογαριασμό e-timologiera:

  1. Επισκεφθείτε einvoicing.etimologiera.gr και πατήστε Εγγραφή
  2. Συμπληρώστε τα στοιχεία επιχείρησης (ΑΦΜ, email, τηλέφωνο)
  3. Υπογράψτε ηλεκτρονικά τη σύμβαση με τον πάροχο BRATNET E.E.
  4. Από το dashboard → ΤΑ ΣΤΟΙΧΕΙΑ ΜΟΥ → API → «Δημιουργία κωδικού»
  5. Αντιγράψτε το Username (email) και το API Key και καταχωρίστε τα παρακάτω

Για βοήθεια: info@etimologiera.gr · +30 2310 989465
