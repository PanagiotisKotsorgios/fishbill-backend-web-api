FishBill — User Flow Diagrams

Main workflows and process flows of the FishBill platform

📄 Ροή Δημιουργίας Τιμολογίου

Ο ψαράς δημιουργεί τιμολόγιο → Επαλήθευση API → Μετάδοση στο myDATA → Λήψη MARK αριθμού

👤 Ροή Εγγραφής Χρήστη

Νέος χρήστης εγγράφεται → Admin εγκρίνει → Ενεργοποίηση λογαριασμού → Email επιβεβαίωσης

👨‍💼 Ροή Διαχείρισης Λογιστή

Λογιστής προσθέτει πελάτη → Παρακολουθεί τιμολόγια → Διαχειρίζεται συνδρομές → Εξάγει αναφορές

💳 Ροή Συνδρομής / Πληρωμής

Χρήστης επιλέγει πλάνο → Πληρωμή → Ενεργοποίηση → Ανανέωση ή Ακύρωση
