Ελληνική Έκδοση

1. Τι είναι τα Cookies;

Τα cookies είναι μικρά αρχεία κειμένου που αποθηκεύονται στη συσκευή σας όταν επισκέπτεστε μια ιστοσελίδα. Χρησιμοποιούνται για να «θυμάται» η εφαρμογή τις προτιμήσεις σας και να λειτουργεί σωστά.

Στο Αγρότης, η εφαρμογή χρησιμοποιεί κυρίως localStorage (τεχνολογία του browser) για αποθήκευση τοπικά, το οποίο εξυπηρετεί παρόμοιο σκοπό με τα cookies. Επίσης χρησιμοποιούμε ελάχιστα τεχνικά cookies για τη λειτουργία της υπηρεσίας.

2. Cookies που Χρησιμοποιούμε

Όνομα / ΚλειδίΤύποςΣκοπόςΔιάρκεια
fishbill_token Απαραίτητο Αποθήκευση JWT token ταυτοποίησης (localStorage) 7 ημέρες (ή έως αποσύνδεση)
fishbill_refresh_token Απαραίτητο Token ανανέωσης συνεδρίας (localStorage) 30 ημέρες
fishbill_user Απαραίτητο Αποθήκευση βασικών στοιχείων χρήστη για εμφάνιση UI (localStorage) Όσο διαρκεί η συνεδρία
fishbill_debug Λειτουργικό Ρύθμιση debug mode για developers (localStorage, προαιρετικό) Μόνιμο έως χειροκίνητη αφαίρεση

Δεν χρησιμοποιούμε cookies τρίτων για διαφήμιση, tracking ή profiling.

3. Κατηγορίες Cookies κατά Οδηγία ΕΕ

  • Απολύτως Απαραίτητα — Χωρίς αυτά η υπηρεσία δεν λειτουργεί. Δεν απαιτείται συγκατάθεση (άρθρο 5§3 Οδηγίας 2002/58/ΕΚ).
  • Λειτουργικά — Βελτιώνουν την εμπειρία χρήσης. Απαιτείται συγκατάθεση — αλλά στην περίπτωσή μας (debug mode) αφορά μόνο developers.
Ενημέρωση: Τα cookies «Απαραίτητα» ενεργοποιούνται αυτόματα για τη λειτουργία της υπηρεσίας. Με τη σύνδεσή σας στο Αγρότης, αποδέχεστε τη χρήση τους. Κανένα cookie για διαφήμιση ή tracking δεν χρησιμοποιείται.

4. Πώς να Διαχειριστείτε τα Cookies

Μπορείτε να διαγράψετε τα αποθηκευμένα δεδομένα (localStorage) από τον browser σας:

  • Chrome: Ρυθμίσεις → Απόρρητο → Εκκαθάριση δεδομένων → Αποθηκευμένα δεδομένα ιστότοπου
  • Firefox: Ρυθμίσεις → Απόρρητο → Διαγραφή δεδομένων → Αποθηκευμένα δεδομένα
  • Safari: Προτιμήσεις → Απόρρητο → Διαχείριση δεδομένων ιστότοπου

Σημείωση: Η διαγραφή αυτών των δεδομένων θα σας αποσυνδέσει από το Αγρότης.

5. Cookies Τρίτων (CDN)

Η εφαρμογή φορτώνει πόρους από:

  • cdn.tailwindcss.com — CSS framework (δεν θέτει cookies)
  • cdn.jsdelivr.net — Chart.js library (δεν θέτει cookies)
  • fonts.googleapis.com — Google Fonts (ο server της Google ενδέχεται να καταγράψει το IP σας, σύμφωνα με την πολιτική της Google)

Για φόντα Google, η λήψη γίνεται απευθείας από τον server της Google. Για πληροφορίες σχετικά με τη συλλογή δεδομένων από Google ανατρέξτε στη Πολιτική Απορρήτου Google.

English Version

1. What Are Cookies?

Cookies are small text files stored on your device when you visit a website. They help the application remember your preferences and function correctly.

Αγρότης primarily uses localStorage (a browser technology) to store data locally, which serves a similar purpose to cookies. We also use a minimal set of technical cookies required for the service to operate.

2. Cookies We Use

Name / KeyTypePurposeDuration
fishbill_token Essential Stores JWT authentication token (localStorage) 7 days (or until sign-out)
fishbill_refresh_token Essential Session renewal token (localStorage) 30 days
fishbill_user Essential Stores basic user info for UI display (localStorage) Duration of session
fishbill_debug Functional Debug mode setting for developers (localStorage, optional) Persistent until manually removed

We do not use third-party cookies for advertising, tracking, or profiling.

3. Cookie Categories under EU Directive

  • Strictly Necessary — Without these the service cannot function. No consent required (Article 5§3 of Directive 2002/58/EC).
  • Functional — Improve the user experience. Consent required — but in our case (debug mode) this applies to developers only.
Notice: Essential cookies are activated automatically for the service to function. By signing in to Αγρότης, you accept their use. No advertising or tracking cookies are used.

4. How to Manage Cookies

You can delete stored data (localStorage) from your browser:

  • Chrome: Settings → Privacy → Clear browsing data → Cached images and files / Site data
  • Firefox: Settings → Privacy → Clear Data → Cached Web Content / Site Data
  • Safari: Preferences → Privacy → Manage Website Data

Note: Deleting this data will sign you out of Αγρότης.

5. Third-Party Cookies (CDN)

The application loads resources from:

  • cdn.tailwindcss.com — CSS framework (sets no cookies)
  • cdn.jsdelivr.net — Chart.js library (sets no cookies)
  • fonts.googleapis.com — Google Fonts (Google's server may log your IP address, per Google's own policy)

Google Fonts are loaded directly from Google's servers. For information on data collection by Google, please refer to the Google Privacy Policy.
