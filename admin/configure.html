Οδηγός Παραμετροποίησης
⚠️ ΑΠΟΘΗΚΕΥΣΤΕ ΤΑ ΠΑΡΑΚΑΤΩ ΣΤΟΙΧΕΙΑ ΣΤΟ EXCEL ΣΑΣ
Καταγράψτε όλα τα διαπιστευτήρια (Taxisnet, myDATA UserID, Subscription Key) σε ασφαλές αρχείο Excel αμέσως μόλις τα λάβετε. Χωρίς αυτά δεν θα μπορείτε να επαναφέρετε τη σύνδεση αν χαθούν.
1
Στοιχεία Επιχείρησης (tab: Στοιχεία)
Ζητήστε από τον ψαρά και συμπληρώστε στο tab Στοιχεία:
ΑΦΜ (αριθμός φορολογικού μητρώου)
Επωνυμία / Εμπορική ονομασία
ΔΟΥ (αρμόδια εφορία)
Διεύθυνση / Πόλη / ΤΚ
Τηλέφωνο & Email επικοινωνίας
ΚΑΔ κύριας δραστηριότητας
Καθεστώς ΦΠΑ (κανονικό / μικρή επιχ.)
Κωδικός αλιέα (fishing_license)
Σειρά τιμολογίων (π.χ. Α, ΑΑ, ΑΛ)
Προεπιλεγμένος συντελεστής ΦΠΑ (13% / 9%)
Στοιχεία λογιστή (όνομα, email, τηλ.)
2
Taxisnet Διαπιστευτήρια (tab: ΓΓΠΣ)
Ζητήστε από τον ψαρά τα στοιχεία Taxisnet — απαραίτητα για πρόσβαση στην ΑΑΔΕ:
Username Taxisnet: ο κωδικός εισόδου του φορολογούμενου στο gsis.gr
Password Taxisnet: ο κωδικός πρόσβασης
ΑΠΟΘΗΚΕΥΣΤΕ ΣΤΗΝ ΣΤΗΛΗ "TAXISNET" ΤΟΥ EXCEL ΣΑΣ
Συμπληρώστε τα στο tab ΓΓΠΣ της παραμετροποίησης και αποθηκεύστε.
3
ΑΑΔΕ myDATA API Keys (tab: myDATA)
Ακολουθήστε τα παρακάτω βήματα για να αποκτήσετε τα API κλειδιά myDATA για αυτόν τον ψαρά:
  1. Συνδεθείτε στο mydata.aade.gr με τα Taxisnet credentials του ψαρά (Βήμα 2)
  2. Μεταβείτε στο μενού «Διαχείριση Συνδρομών» ή «Εγγραφή στο myDATA»
  3. Δημιουργήστε νέα συνδρομή / εγγραφή → θα παραχθεί:
    UserID: το όνομα χρήστη ΑΑΔΕ (π.χ. user123456789)
    Subscription Key: μακρύ αλφαριθμητικό κλειδί (π.χ. a1b2c3d4e5f6...)
  4. Καταχωρήστε και τα δύο στο tab myDATA της παραμετροποίησης
ΑΠΟΘΗΚΕΥΣΤΕ UserID + Subscription Key ΣΤΗΝ ΣΤΗΛΗ "myDATA" ΤΟΥ EXCEL ΣΑΣ
⚡ Για sandbox/δοκιμές: mydata-dev-register.azurewebsites.net — αλλά για παραγωγή χρησιμοποιείτε πάντα mydata.aade.gr (πραγματικά credentials).
4
Τελικές Ρυθμίσεις & Ενεργοποίηση
Κατάσταση (tab: Κατάσταση): Ορίστε πρόγραμμα (basic/pro), ενεργοποιήστε τη συνδρομή και σημειώστε ημερομηνία λήξης
ΦΠΑ & Σειρές (tab: Στοιχεία): Ορίστε προεπιλεγμένο ΦΠΑ (13% αλιεύματα / 9% νησιά) και σειρά τιμολογίων
Δοκιμαστική διαβίβαση: Δημιουργήστε ένα δελτίο αποστολής ή τιμολόγιο και ελέγξτε ότι επιστρέφεται MARK από την ΑΑΔΕ
Ενημέρωση χρήστη: Στείλτε email με οδηγίες χρήσης της εφαρμογής
ΥΠΕΝΘΥΜΙΣΗ EXCEL — Τι να αποθηκεύσετε:
✓ ΑΦΜ ψαρά
✓ Taxisnet username
✓ Taxisnet password
✓ myDATA UserID
✓ myDATA Subscription Key
✓ Σειρά τιμολογίων
✓ Πρόγραμμα (basic/pro)
✓ Ημ/νία ενεργοποίησης
