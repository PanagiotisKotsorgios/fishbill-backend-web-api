Πάροχος Τιμολόγησης — e-timologiera

Διαπιστευτήρια σύνδεσης με e-timologiera για αποστολή παραστατικών στο myDATA/ΑΑΔΕ. Τα Δελτία Αποστολής χρησιμοποιούν τα credentials myDATA κάθε επιχείρησης ξεχωριστά.

e-timologiera — BRATNET E.E. (Πιστοποιημένος Πάροχος ΑΑΔΕ)

Το FishBill αποστέλλει όλα τα παραστατικά (Τιμολόγια + Δελτία Αποστολής) μέσω e-timologiera V4 API. Ο πάροχος επικυρώνει, υπογράφει και προωθεί κάθε παραστατικό στο myDATA/ΑΑΔΕ — επιστρέφει MARK, QR Code και ψηφιακή υπογραφή. Endpoint: POST /sendInvoice για όλους τους τύπους.

e-timologiera — BRATNET E.E. (Πιστοποιημένος Πάροχος ΑΑΔΕ)

Αποστέλλετε παραστατικά στο API του e-timologiera (Basic Auth) και αυτοί αναλαμβάνουν την επικύρωση και μετάδοση στο myDATA/ΑΑΔΕ. Επιστρέφουν MARK, QR Code και ψηφιακή υπογραφή.

📄 API Docs 🔬 Swagger (Dev) 📞 2310 989465 · info@etimologiera.gr

V4 API — Production: https://einvoicing-api.etimologiera.gr/v4

V4 API — Sandbox: https://einvoicing-dev-api.etimologiera.gr/v4

Auth: HTTP Basic Auth — Username + API Key (από το dashboard της e-timologiera → ΤΑ ΣΤΟΙΧΕΙΑ ΜΟΥ → API)

Endpoint: POST /sendInvoice — και για Τιμολόγια και για Δελτία Αποστολής

Δημιουργία κωδικού: Σύνδεση → ΤΑ ΣΤΟΙΧΕΙΑ ΜΟΥ → API → «Δημιουργία κωδικού»

Δελτία Αποστολής — μέσω e-timologiera (τύπος 9.3)

Τα Δελτία Αποστολής αποστέλλονται επίσης μέσω e-timologiera (ίδια credentials παραπάνω) με τύπο παραστατικού 9.3. Δεν χρειάζονται ξεχωριστά credentials myDATA ανά επιχείρηση.

✅ Τιμολόγια Πώλησης (1.1) → POST /sendInvoice

✅ Δελτία Αποστολής (9.3) → POST /sendInvoice

✅ Πιστωτικά Τιμολόγια (1.3) → POST /sendInvoice
