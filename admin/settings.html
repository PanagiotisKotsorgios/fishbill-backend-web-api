Διαπιστευτήρια myDATA (ΑΑΔΕ)

Τα δικά σας credentials από το myDATA portal της ΑΑΔΕ — χρησιμοποιούνται για άμεση μετάδοση ή ως fallback.

Τα credentials αποθηκεύονται στον server και δεν εμφανίζονται ξανά.

Περιβάλλον ΑΑΔΕ myDATA — Δελτία Αποστολής

Ισχύει μόνο για τη άμεση μετάδοση δελτίων αποστολής προς την ΑΑΔΕ. Επιλέξτε Production για πραγματικές μεταδόσεις.

Λειτουργία Test (Sandbox ΑΑΔΕ)

OFF = Production (πραγματικές μεταδόσεις στο myDATA)  ·  ON = Test sandbox

Test mode ενεργό! Τα δελτία αποστολής στέλνονται στο SANDBOX της ΑΑΔΕ και δεν παράγουν πραγματικό MARK. Απενεργοποιήστε για παραγωγή.

Τρόπος Μετάδοσης στο myDATA

Επιλέξτε έναν τρόπο. Αν δεν έχετε ρυθμίσει τίποτα, οι μεταδόσεις είναι ανενεργές. Μόνο ο ενεργός τρόπος θα χρησιμοποιείται.

Μόνο ένας τρόπος μπορεί να είναι ενεργός ταυτόχρονα. Η επιλογή "Ανενεργό" σταματά όλες τις μεταδόσεις.

Credentials ΓΓΠΣ (Αναζήτηση ΑΦΜ)

Προαιρετικά. Χρησιμοποιούνται για αυτόματη αναζήτηση στοιχείων επιχείρησης βάσει ΑΦΜ μέσω ΓΓΠΣ/ΑΑΔΕ.

Email Πάροχος

Αποστολή τιμολογίων & ειδοποιήσεων μέσω email

Brevo (brevo.com) — Δωρεάν έως 300 emails/ημέρα. Δημιουργήστε API key από Brevo Dashboard → Settings → API Keys.
SendGrid (sendgrid.com) — Δωρεάν έως 100 emails/ημέρα. API key από Settings → API Keys.
Mailgun (mailgun.com) — 1000 emails/μήνα δωρεάν. Χρειάζεται verified domain.

SMS Πάροχος

Αποστολή SMS ειδοποιήσεων για τιμολόγια & IRIS

Μέγιστο 11 χαρακτήρες, χωρίς ειδικά σύμβολα.

Infobip (infobip.com) — Δημιουργήστε λογαριασμό, πάρτε το API Key και το base URL από το dashboard.
Apifon (apifon.com) — Ελληνικός πάροχος. API key από το dashboard.
Routee (routee.net) — Θυγατρική OTE/COSMOTE. Application Key από Routee Dashboard.
BSMS (bsms.gr) — Ελληνικός πάροχος SMS.
Yuboto (yuboto.com) — Ελληνικός πάροχος SMS & Viber.
